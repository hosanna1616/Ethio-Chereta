# EthioChereta

**EthioChereta** is a web app for **tender management in Ethiopia** — discover tenders, track bids, see analytics, and manage your account. It includes a marketing home page, sign-in / registration, and a signed-in dashboard with sidebar navigation on desktop and a mobile-friendly layout on smaller screens.
